# Hotel Group & Corporate Rate Leakage Recovery

Find hotel revenue leakage from incorrect negotiated rates, concessions, room blocks, commissions, and rate-code misuse.

**Primary buyer:** Hotel groups and management companies. **Evidence:** negotiated rate agreements, room inventory, reservations, stay dates, rate codes, blackout dates, last-room availability, commissions, folios, and payments.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Rate agreement library
- Account property mapping
- Room block registry
- Reservation ingestion
- Rate code validation
- Stay-date eligibility
- Blackout date control
- Last-room availability
- Concession package audit
- Attrition calculation
- Cancellation fee validation
- Commission treatment
- Folio rate correction
- Account recovery workflow
- Property account analytics
